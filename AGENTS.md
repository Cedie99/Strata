# Keep the user manual current

The user manual is a set of published pages whose sources are in `docs/manual/`. Whenever a change adds,
removes or alters anything a user sees or does (screens, fields, buttons, menus, permissions, numbering,
postings, how modules connect), update and republish the matching manual pages in the same piece of work,
following `docs/manual/README.md`. A feature is not done until its manual page is.

The product roadmap is `ROADMAP.md` (not README.md): tick items there as they are finished.

# This is NOT the Next.js you know

This version has breaking changes — APIs, conventions, and file structure may all differ from your training data. Read the relevant guide in `node_modules/next/dist/docs/` before writing any code. Heed deprecation notices.
