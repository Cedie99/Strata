Build your own records

When the company needs to track something Strata does not have (vehicles, trips, contracts, an item master), an administrator can build it under Setup without writing code. Strata creates the list, the form, the menu and the permissions.

The parts of a module

A module holds one or more record types; each record type has its own fields and records.

Where it lives

Setup → Customization ► Modules

Needs the permission "Build and change custom modules". Each module's records are at /m/<module>/<record type>.

  • Show in menu: give the module its own menu, or place it inside a built-in one (e.g. under Inventory), optionally in a named ► submenu shared with other modules (e.g. Setup ► Inventory/WMS ► Item Master).
  • Each module adds three permissions to the Roles screen: view, manage (create and edit) and approve records.
  • Active custom modules show as quick links on the home page for people who can open them.

Options

Per field and per record type.

Per field

  1. Required, default value (today for dates), unique.
  2. Show in list, searchable, help text.
  3. Lock after creation.
  4. Show only when another field has certain values.
  5. For lookups: filter by another field (e.g. Item Class by Item Type).

Per record type

  1. One-page or tabbed form (each section heading becomes a tab).
  2. Rules every record must pass, e.g. price >= cost.
  3. Approval: new and changed records stay Pending until a different user with "approve" decides.
  4. Related records: a lookup from Trips to Vehicles lists a vehicle's trips on its page, or shows them as editable lines inside the vehicle's form.
FormulasCalculated fields and rules use a small formula language: + − × ÷ %, comparisons, and / or / not, and the functions round floor ceil abs min max if empty len days. Example: round(qty * price, 2).

How to

A worked example.

Track company vehicles

  1. Setup → Modules → New: name "Fleet", own menu.
  2. Add record type "Vehicles": Plate no. (text, unique), Model, Assigned to (lookup to users), Registration expiry (date).
  3. Add record type "Trips": Vehicle (lookup to Vehicles), Date, Odometer start/end, Distance (calculated: end − start).
  4. Add the rule odometer_end >= odometer_start.
  5. Give the "view"/"manage" permissions to the right roles.

Load existing data

  1. Open the record type's list → Import → download the template.
  2. Fill it in Excel and upload.
  3. If any row breaks a rule, nothing is saved and every problem is listed.

Limits

What custom modules do not do.

No stock or accounting postings.Custom records never change stock or the general ledger. Anything that must post to Inventory or Accounting is built as a code module (like Purchasing).
  • Removing a field hides its values without deleting them.
  • A module or record type that still has records cannot be removed; deactivate the module instead.
